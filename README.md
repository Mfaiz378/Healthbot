# 🩺 HealthBot - Full Stack AI Health Assistant

A full-stack AI-powered HealthBot web application that allows users to log in, chat with a health-focused bot (powered by Dialogflow), view nearby hospitals on a map (via Leaflet API), and manage basic user data securely. Built using React, Spring Boot, MySQL.
---

## 🛠️ Tech Stack

**Frontend**:
- React.js
- CSS
- Leaflet API
- Axios for API requests

**Backend**:
- Spring Boot
- Hibernate (JPA)
- RESTful APIs
- Dialogflow integration
- MySQL Database

**Tools & Deployment**:
- Netlify (Frontend hosting)
- Railway/Render (Backend hosting)
- Git & GitHub
- Postman (API testing)

---

## 🔐 Features

- ✅ User Signup/Login with MySQL integration
- 💬 Chatbot using Dialogflow
- 🏥 Locate nearby hospitals using Google Maps API
- 🔒 JWT Authentication & Spring Security (optional upgrade)
- 🐳 Docker support for backend deployment
